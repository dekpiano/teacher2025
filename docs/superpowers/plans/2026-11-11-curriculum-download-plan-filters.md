# แผนการปรับปรุงระบบสืบค้นและดาวน์โหลดแผนการสอน (Curriculum Download Plan Filters)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## ภาพรวม (Overview)
ปรับปรุงระบบสืบค้นและดาวน์โหลดแผนการสอน (`https://localhost:8084/curriculum/download-plan`) ใน `teacher2025` ให้ครอบคลุมทุกบทบาทผู้ใช้งาน และแก้ไขข้อผิดพลาดที่ครูซึ่งเปลี่ยนตำแหน่ง (เช่น เป็นรองผู้อำนวยการ, ย้ายสายงาน หรือไม่มี `pers_learning` ในปัจจุบัน) ไม่สามารถดูรายวิชาที่เคยสอนและส่งแผนในระบบได้

## ปัญหาที่พบในระบบเดิม (Root Causes)
1. **Dropdown รายชื่อครูผู้สอน (`SelTeacher`):** ดึงเฉพาะ `tb_personnel` ที่มี `pers_learning` ตรงกับกลุ่มสาระของผู้ที่ล็อกอินอยู่ ส่งผลให้ครูที่เปลี่ยนตำแหน่ง (เช่น รอง ผอ. อรอุมา ฉวีทอง `pers_127` ซึ่งใน `tb_personnel` ไม่มีสังกัดกลุ่มสาระแล้ว) ไม่ปรากฏชื่อในระบบ ทั้งที่มีประวัติแผนในระบบถึง 132 แผน
2. **เงื่อนไข Query แผนการสอน (`$builder`):** ล็อก `where('seplan_learning', $CheckLearning->pers_learning)` อิงตามกลุ่มสาระของผู้เปิดดู หากผู้บริหารหรือครูต่างกลุ่มสาระเปิดดู หรือครูเคยสอนวิชาในกลุ่มสาระอื่น จะไม่พบข้อมูลรายวิชา
3. **ขาดตัวกรองกลุ่มสาระการเรียนรู้:** ทำให้ค้นหาได้เฉพาะกลุ่มสาระของผู้ล็อกอิน ไม่สามารถสืบค้นข้ามกลุ่มสาระเพื่อการจัดการเรียนรู้เชิงบูรณาการได้

## สถาปัตยกรรมและการแก้ไข (Proposed Architecture)
1. **Controller (`app/Controllers/CurriculumController.php` - `loadPlan`):**
   - รองรับพารามิเตอร์ทั้งรูปแบบ Route Segment และ Query Parameters (`learning`, `year`, `term`, `teacher`)
   - ดึงรายชื่อกลุ่มสาระทั้งหมดจาก `tb_learning` ส่งให้ View
   - ดึงรายชื่อครูผู้สอนแบบบูรณาการ: รวมทั้ง **ครูทุกคนที่เคยมีประวัติส่งแผนในกลุ่มสาระนั้น (`tb_send_plan`)** + **ครูปัจจุบันในกลุ่มสาระ (`tb_personnel`)** พร้อมแสดงตำแหน่ง/สังกัดอย่างชัดเจน
   - เมื่อเลือกครูผู้สอน: Query แผนตาม `seplan_usersend`, `seplan_year`, `seplan_term` โดยไม่ถูกจำกัดด้วยกลุ่มสาระของผู้ล็อกอิน
   - เพิ่ม AJAX Endpoint `getTeachersByLearning` เพื่อให้ Dropdown ครูอัปเดตแบบ Realtime เมื่อผู้ใช้เปลี่ยนกลุ่มสาระ
2. **View (`app/Views/teacher/curriculum/plan_loadplan.php`):**
   - ออกแบบตัวกรองใหม่ 3 มิติ:
     1. **กลุ่มสาระการเรียนรู้** (Default: กลุ่มสาระของผู้ล็อกอิน หรือ "ทุกกลุ่มสาระ" หากเป็นผู้บริหาร)
     2. **ครูผู้สอน** (Select2 รองรับค้นหาชื่อ รวมครูในอดีตและปัจจุบัน)
     3. **ปีการศึกษา / ภาคเรียน** (เรียงจากปีล่าสุดลงมา)
   - ปรับปรุงการแสดงผลตาราง: แสดงแถบสรุปข้อมูลครูที่กำลังสืบค้น, แสดงชื่อครูในกรณีเลือกดู "ครูทุกคนในกลุ่มสาระ" และคงสไตล์ Sneat Admin Template ที่รองรับ Mobile-First

## แผนการดำเนินงาน (Tasks)

### Task 1: พัฒนาระบบดึงข้อมูลครูและแผนการสอนใน Controller (`CurriculumController.php`)
- [ ] อัปเดตเมธอด `loadPlan` ใน `app/Controllers/CurriculumController.php`:
  - ดึงข้อมูลกลุ่มสาระการเรียนรู้ทั้งหมด (`$data['learnings']`) จาก `tb_learning`
  - ตรวจสอบ `$selectedLearning`: ถ้าเป็นค่าว่าง ให้ใช้กลุ่มสาระของผู้ล็อกอิน (หากผู้ล็อกอินไม่มีกลุ่มสาระ ให้ใช้ `'All'`)
  - สร้าง Query ดึงครู (`$data['SelTeacher']`) จากประวัติการส่งแผน `tb_send_plan` UNION กับ `tb_personnel` ตามกลุ่มสาระที่เลือก
  - ปรับปรุง Query `$builder` สำหรับดึงแผนการสอน ไม่ล็อกกลุ่มสาระกับผู้ล็อกอิน แต่กรองตาม `$selectedLearning` (ถ้าไม่ใช่ All) และ `$selectedTeacher` (ถ้าไม่ใช่ All)
  - จัดเรียงปีการศึกษา/ภาคเรียน (`$data['CheckYear']`) ล่าสุดขึ้นก่อน (`DESC`)
- [ ] เพิ่มเมธอด AJAX `getTeachersByLearning` ใน `CurriculumController.php` เพื่อคืนค่า JSON รายชื่อครูตามกลุ่มสาระที่เลือก
- [ ] เพิ่ม Route ใน `app/Config/Routes.php` สำหรับรองรับ AJAX และ Query Parameters
